# Srez

Приложение для macOS, которое превращает запись встречи в протокол на русском языке.
Srez распознаёт речь локально с помощью GigaAM v3 и собирает резюме, решения,
задачи и открытые вопросы через Codex.

Аудио остаётся на Mac. Распознанный текст отправляется через Codex для суммаризации.

## Требования

- Mac с Apple Silicon и macOS 14 или новее.
- Xcode с поддержкой формата иконок Icon Composer (`AppIcon.icon`) для сборки.
- Установленные `ffmpeg` и Codex CLI с текущей авторизацией.
- Скачанная модель [GigaAM v3 MLX](https://huggingface.co/kruatech/gigaam-v3-mlx).

## Быстрый старт

Скачайте модель через Hugging Face CLI:

```bash
hf download kruatech/gigaam-v3-mlx \
  --repo-type model \
  --local-dir Models/GigaAM-v3-MLX
```

Соберите и откройте приложение:

```bash
make build
open .build/Srez.app
```

Команда `make` тоже собирает приложение. Сборка включает движок MLX, Metal-шейдеры
и иконку. Приложение подписывается локально для личного использования, без нотариализации.

В настройках проверьте пути к модели, `ffmpeg`, Codex и папке результатов.
Папка модели остаётся внешней: после перемещения репозитория её путь нужно обновить.
Там же можно выбрать модель Codex, уровень рассуждения (low, medium, high)
и сохранение сырой расшифровки. Пользовательский `config.toml` не загружается.

## Работа со встречами

При запуске Srez предлагает выбрать MP3, WAV, WebM или MP4. Можно выбрать несколько
файлов — они обрабатываются последовательно. Также работает Finder →
«Открыть в программе» → Srez; дополнительный диалог выбора в этом случае не появляется.

Обработка проходит три этапа: преобразование аудио через ffmpeg, локальное
распознавание речи и суммаризация через Codex. Во время распознавания виден процент
обработанного аудио, на остальных этапах — их название. Длинные расшифровки
суммаризируются частями.

Результаты по умолчанию сохраняются в `~/Documents/Встречи`:

- `<тема встречи>.md` — резюме, обсуждавшиеся вопросы, решения, задачи и открытые вопросы.
- `<тема встречи>.raw.txt` — исходная расшифровка, если включено её сохранение.

При совпадении имён добавляется номер. Существующие файлы не перезаписываются.
Готовый протокол можно открыть из приложения или показать в Finder.

Отмена распознавания срабатывает между фрагментами. При ошибке Codex можно повторить
суммаризацию без повторного распознавания: текст хранится в памяти до выхода
из приложения. Очередь между запусками не сохраняется. Изменения настроек
применяются к следующему заданию или повторной попытке.

## Разработка

Основной и единственный продукт Swift-пакета — приложение `Srez` для macOS.
`GigaAMKit` — внутренний модуль распознавания на MLX Swift.

```bash
make build  # собрать .build/Srez.app
make test   # проверить приложение и движок
make clean  # удалить артефакты сборки
```

Прежние команды `make app` и `make app-test` сохранены как псевдонимы.
Тесты не требуют скачанной модели и не обращаются к Codex: внешний процесс
подменяется локальным тестовым скриптом.

- `Sources/Srez` — интерфейс, очередь, настройки и обработка встреч.
- `Sources/GigaAMKit` — загрузка аудио, mel-спектрограмма, Conformer/RNNT и токенизация.
- `App` и `AppIcon.icon` — метаданные приложения и иконка.
- `scripts/build-app.sh` — сборка, упаковка и локальная подпись приложения.
- `Tests` — проверки приложения и движка распознавания.
