# Srez

Приложение для macOS, которое превращает запись встречи в протокол на русском языке.
Srez распознаёт речь локально с помощью GigaAM v3, а по кнопке Summarize собирает
протокол с автоматическим определением типа встречи через Codex.

Аудио остаётся на Mac. Распознанный текст отправляется через Codex только при запуске суммаризации.

## Требования

- Mac с Apple Silicon и macOS 14 или новее.
- Xcode с поддержкой формата иконок Icon Composer (`AppIcon.icon`) для сборки.
- Для суммаризации — установленный Codex CLI с текущей авторизацией.
- Интернет для первого скачивания модели, исходников FFmpeg при сборке и суммаризации через Codex.

## Быстрый старт

Соберите и откройте приложение:

```bash
make build
open .build/Srez.app
```

Команда `make` тоже собирает приложение. Сборка включает движок MLX, Metal-шейдеры,
иконку и FFmpeg. Устанавливать FFmpeg отдельно не нужно. Приложение подписывается
локально для личного использования, без нотариализации.

При первой сборке скачиваются исходники FFmpeg 9.0.2 с проверкой SHA-256.
Скрипт собирает отдельный исполняемый файл для Apple Silicon и macOS 14+, который
зависит только от системных библиотек macOS. Готовый файл кэшируется в `.build/ffmpeg`.
В приложение также включены исходники, конфигурация сборки и лицензия LGPL 2.1+.

При первом распознавании Srez автоматически скачивает модель
[GigaAM v3 MLX](https://huggingface.co/kruatech/gigaam-v3-mlx) (около 445 МБ) в
`~/Library/Application Support/Srez/Models/GigaAM-v3-MLX`.
Версия модели закреплена, файлы проверяются по SHA-256. Готовая модель используется
без повторного скачивания. После сбоя или отмены достаточно повторить задание:
проверенные файлы сохраняются, недостающие или повреждённые скачиваются заново.

В настройках проверьте пути к Codex и папке результатов.
Там же можно выбрать модель Codex и уровень рассуждения (low, medium, high).
Если Codex CLI не найден по указанному пути, настройки подскажут установить его
и авторизоваться. Кнопка Summarize и пункт суммаризации в контекстном меню
появляются только при наличии исполняемого файла Codex. Проверка обновляется
при изменении пути и возврате в приложение; авторизация автоматически не проверяется.
Расшифровка сохраняется всегда. Пользовательский `config.toml` не загружается.

## Работа со встречами

При запуске Srez предлагает выбрать MP3, WAV, WebM, MP4 или M4A. Можно выбрать несколько
файлов — они расшифровываются последовательно. Также работает Finder →
«Открыть в программе» → Srez; дополнительный диалог выбора в этом случае не появляется.
Записи можно перетащить из Finder в окно Srez — они сразу попадут в очередь расшифровки.
Если список пуст, окно скрыто, а нажатие на значок Srez в Dock снова открывает выбор файла.
Кнопка папки в панели окна добавляет записи, внизу показана папка результатов.

По умолчанию приложение преобразует аудио через ffmpeg, распознаёт речь локально
и сохраняет расшифровку. Во время распознавания виден процент обработанного аудио,
на остальных этапах — анимированный индикатор и название.

У готовой расшифровки слева от лупы появляется кнопка Summarize. Она запускает
суммаризацию через Codex в отдельной очереди, без повторного распознавания аудио.
Расшифровка и суммаризация работают параллельно, по одному заданию каждого типа.
Чтобы получить общий конспект нескольких записей, выделите готовые записи через ⌘‑клик
и нажмите появившуюся снизу кнопку «Суммаризировать вместе». Выбранные строки подсвечиваются
акцентным цветом; повторный ⌘‑клик снимает выделение. Можно выбрать и записи с готовым конспектом:
для объединения всегда используются исходные расшифровки. Тексты объединяются
в порядке списка, результат появляется отдельным заданием. Общая расшифровка
сохраняется в отдельный `.raw.txt`, конспект — в `.md`; исходные файлы остаются на месте.
Тип определяется автоматически по цели разговора: проектная встреча, 1:1, клиент / Sales,
интервью / Q&A, User Research или ретро. Если цель неясна или встреча другого типа,
используется общая структура. В смешанной встрече сохраняются блоки разных типов.

Протокол содержит только заполненные разделы: краткое резюме, обсуждавшиеся вопросы,
решения, задачи и открытые вопросы. Обсуждение организовано по типу: например,
в интервью сохраняется связь вопроса, ответа, уточнений и примеров, а в проектной встрече —
статусы направлений, блокеры и зависимости. Для найма фиксируются свидетельства без
автоматического вердикта о кандидате. Ответственные и сроки указываются только при явной
договорённости; неизвестные поля задачи отмечаются. Без явного имени владельца нельзя
определить по фразе «я сделаю». Относительные сроки сохраняются как прозвучали.

В длинных расшифровках сначала извлекаются факты по частям со ссылками на исходные
фрагменты и перекрытием границ, затем собирается общий протокол с учётом уточнений и отмен.
Структура ответа, ссылки на фрагменты и дословность цитат проверяются приложением,
Markdown собирается из данных. Каждый запрос, включая инструкции, ограничен 96 КиБ UTF-8.
Если извлечённые факты не помещаются, приложение дополнительно объединяет их по частям,
сохраняя ссылки на исходную речь. Если сжатие не даёт достаточного уменьшения, обработка
останавливается с предложением разбить запись или выбрать меньше встреч; расшифровка остаётся на диске.
Эти проверки не заменяют проверку смысла по расшифровке.
После создания резюме кнопка Summarize исчезает.

Результаты по умолчанию сохраняются в `~/Documents/Встречи`:

- `<имя записи>.raw.txt` — исходная расшифровка, сохраняется сразу после распознавания.
- `<тема встречи>.md` — протокол по типу встречи с заполненными разделами; создаётся по кнопке Summarize.

При совпадении имён добавляется номер. Существующие файлы не перезаписываются.
Двойное нажатие на строку или контекстное меню открывает расшифровку, а после
суммаризации — резюме. Кнопка лупы показывает соответствующий файл в Finder.
Расшифровка остаётся на диске и доступна через контекстное меню после суммаризации.
Крестик убирает запись из списка и отменяет
её обработку, если она ещё не завершена. Сохранённые файлы остаются на диске.

Отмена распознавания срабатывает между фрагментами. При ошибке Codex можно повторить
суммаризацию без повторного распознавания: сохранённая расшифровка остаётся доступна
через кнопку лупы. Если сохранить расшифровку не удалось, текст хранится в памяти
до выхода из приложения для повторной попытки. Очереди между запусками не сохраняются. Изменения настроек
применяются к следующему заданию или повторной попытке.

## Разработка

Основной и единственный продукт Swift-пакета — приложение `Srez` для macOS.
`GigaAM` — внутренний модуль распознавания на MLX Swift.

```bash
make build  # собрать .build/Srez.app
make test   # проверить приложение и движок
make clean  # удалить артефакты сборки
```

Прежние команды `make app` и `make app-test` сохранены как псевдонимы.
Тесты не требуют скачанной модели и доступа к сети: скачивание подменяется
локальными файлами, а Codex — тестовым скриптом.

- `Sources/Srez` — интерфейс, очередь, настройки и обработка встреч.
- `Sources/GigaAM` — загрузка аудио, mel-спектрограмма, Conformer/RNNT и токенизация.
- `App` и `Assets/AppIcon.icon` — метаданные приложения и иконка.
- `scripts/build-app.sh` — сборка, упаковка и локальная подпись приложения.
- `scripts/build-ffmpeg.sh` — сборка встроенного FFmpeg без зависимостей от Homebrew.
- `ThirdParty/FFmpeg` — сведения о FFmpeg и инструкции по пересборке.
- `Tests` — проверки приложения и движка распознавания.
